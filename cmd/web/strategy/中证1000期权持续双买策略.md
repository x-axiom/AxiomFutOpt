# 持续双买策略文档

# 策略参数

- start-date: 回测开始日期
- end-date: 回测结束日期
- hold-days: 最大持有持续日期
- min-dte: 最小到期日
- sell-profit: 波动百分比
- rest-days: 休整日
- max-atr-pct: 平均波动百分比(浮点数)

# 策略操作手册:
- 合约选择原则: 到期日需大于{min-dte}天的最近合约
- 初始建仓: 收盘时, 以中证1000指数close价格为标准, 双买close价上下的CALL和PUT各1张(即ATM期权), 分为2种情况:
  - 1. 若max-atr-pct设置大于0, 以{max-atr-pct}为阈值, 在当日的atr_pct小于参数{max-atr-pct}时才开仓, 否则等待下一个交易日
  - 2. 若max-atr-pct等于0, 则当日atr_pct要小于过去14个交易日atr_pct的平均值时才开仓, 否则等待下一个交易日
- 卖出时机: 1-中证1000指数close价格波动大于{sell-profit}%, 2-持有{hold-days}个自然日依然没有触发止盈则无条件卖出, 3-到期日不足20天无条件卖出
- 重新建仓时机: 通过卖出时机1或2卖出后休整{rest-days}个交易日,如果是通过时机3卖出的则直接重新建仓

# 数据来源:

- 中证1000指数: data/csi1000_daily.csv
- 期权合约数据: data/duckdb/market.duckdb, 其中options_daily表是合约的每日价格, contract_meta表是合约的可交易日期范围
