# 双买策略文档

# 策略参数

- start-date: 回测开始日期
- end-date: 回测结束日期
- hold-days: 持有持续日期
- min-dte: 最小到期日
- sell-profit: 止盈百分比
- rest-days: 休整日

# 策略操作手册:
- 合约选择原则: 到期日需大于{min-dte}天的最近合约
- 初始建仓: 收盘时, 以中证1000指数close价格为标准, 双买close价上下的CALL和PUT各1张(即ATM期权)
- 卖出时机: 1-整体盈利达到{sell-profit}%, 2-持有{hold-days}个自然日依然没有触发止盈则无条件卖出, 3-到期日不足20天无条件卖出
- 重新建仓时机: 通过卖出时机1或2卖出后休整{rest-days}个交易日,如果是通过时机3卖出的则直接重新建仓

# 数据来源:

- 中证1000指数: data/csi1000_daily.csv
- 期权合约数据: data/duckdb/market.duckdb
